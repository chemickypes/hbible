# HBible — contenuti

Branch `gh-pages` del repo dell'app, servito da GitHub Pages. La cartella `content/` contiene i
pacchetti che l'app scarica per aggiornarsi senza una nuova versione (`manifest.json` con lo
SHA-256 di ogni file). È generata dal CMS di HBible: non modificarla a mano.

pubblico dominio; testo ebraico OSHB (morfologia CC BY 4.0); testo greco Nestle 1904 (morfologia CC0);
riferimenti incrociati OpenBible.info CC BY 4.0.
